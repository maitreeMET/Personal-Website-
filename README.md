# Maitree Meher — personal website

Built on [al-folio](https://github.com/alshedivat/al-folio), adapted from [Jonas Frey's site](https://github.com/JonasFrey96/jonasfrey96.github.io).

Run locally:

```bash
export PATH=/opt/homebrew/opt/ruby/bin:$PATH
bundle install
bundle exec jekyll serve --port 8000
```
